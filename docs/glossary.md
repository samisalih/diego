# Glossary

German domain term → English identifier used in code.

| German | English identifier | Meaning |
|---|---|---|
| Dokument | `document` | a complete scene: own copy of the apartment + placed items + lighting |
| Wohnung | `apartment` | rooms, walls, openings and meta data of one document |
| Raum | `room` | polygon on the floor plan with floor/wall/ceiling materials |
| Wand | `wall` | straight wall segment between two points |
| Öffnung | `opening` | window, door or balcony door in a wall |
| Brüstung | `sillHeight` | height of the lower edge of an opening above the floor |
| Asset | `asset` | parametric furniture blueprint in the global library |
| Item | `item` | a placed instance of an asset in a document |
| Teil | `part` | one shape of an asset |
| Regler | `param` | a numeric asset parameter with range, shown as slider |
| Material | `material` | texture set in the global library |
| Modell | `model` | GLB model, used as a part inside assets |
| Werkstatt | `workshop` | asset editor |
| Puppenhaus | `dollhouse` | orbit view from above, ceiling hidden |
| Durchlaufen | `firstPerson` | walk-through view |
| Arbeiten / Foto | `work` / `photo` | realtime / path-traced render mode |
| Papierkorb | `trash` | soft-deleted entries (`deleted_at`) |
| Jahreszeit | `season` | winter, spring, summer, autumn |
| Stimmungs-Layer | `moodLayer` | optional post effect overlay |
| geschätzt | `estimated` | value not measured yet |
| Fase | `bevel` | rounded/chamfered edge radius |
